❓ Các Lỗi Thường Gặp & Cách Khắc Phục

1. Lỗi "Error 403: access_denied" / "App is not verified"

👉 Nguyên nhân: Tài khoản Gmail bạn bấm đăng nhập chưa được thêm vào danh sách Test users ở Bước 4.
👉 Cách sửa: Vào lại Google Cloud Console ➔ APIs & Services ➔ OAuth consent screen ➔ Kéo xuống mục Test users ➔ Bấm + ADD USERS và nhập đúng email đó vào.

2. Màn hình cảnh báo "Google hasn't verified this app" (Màu xám/đỏ)

👉 Xử lý: Đây là cảnh báo tiêu chuẩn của Google cho ứng dụng cá nhân tự tạo. Bạn chỉ cần bấm vào chữ Advanced (Nâng cao) ở góc dưới bên trái ➔ Bấm tiếp Go to Omnisave (unsafe) ➔ Bấm Continue (Tiếp tục) là xong.

3. Lỗi "redirect_uri_mismatch"

👉 Nguyên nhân: Ở Bước 5 bạn lỡ chọn loại Web application thay vì Desktop app.
👉 Cách sửa: Vào Credentials ➔ Tạo một Client ID mới và chắc chắn chọn loại Desktop app (Ứng dụng máy tính).

4. Lỗi "Google Drive API has not been used in project... or it is disabled"

👉 Nguyên nhân: Dự án Google Cloud của bạn chưa Bật (Enable) dịch vụ Google Drive API.
👉 Cách sửa: Bấm trực tiếp nút 🌐 Mở Liên Kết Trong Trình Duyệt ↗ trên bảng báo lỗi của Omnisave (hoặc truy cập đường link dẫn tới trang Enable API mà thông báo hiển thị) ➔ Nhấn nút xanh ENABLE (Bật). Sau khi bật, đợi 1-2 phút cho Google cập nhật rồi thực hiện lại.
